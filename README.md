## Cara Menjalankan

| Pertemuan | Cara menjalankan |
|-----------|------------------|
| 1–2 | Buka `index.html` di browser, atau gunakan ekstensi Live Server di VS Code. |
| 3 | Masuk ke folder proyek, lalu jalankan `npm install` dan `npm run dev`. |
| 4 | Masuk ke folder pertemuan, lalu jalankan `python tugas1_bmi.py`, `python tugas2_nilai_mahasiswa.py`, dan `python main.py`. |

Rincian lengkap ada di README masing-masing folder.
