## Isi Folder

| Folder | Isi |
|--------|-----|
| `Modul/` | Latihan praktikum dari modul: React Task Manager (komponen, state & hooks, routing, custom hook, Context API, testing) beserta semua latihan mandiri |
| `Manajemen Buku/` | Tugas praktikum: aplikasi manajemen buku pribadi |
| `Screenshot/` | Tangkapan layar aplikasi tugas Manajemen Buku dan hasil unit test |

Setiap folder proyek dijalankan terpisah:

```bash
cd "Manajemen Buku"     # atau: cd Modul
npm install
npm run dev
```

Folder `node_modules/` tidak disertakan (sudah ada di `.gitignore`), jadi jalankan `npm install` terlebih dahulu.
